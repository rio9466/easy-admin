# ADR

Architecture decision records for `easy-admin` live here. Owned by the main line
(`main-relay`), later published to `main`.

No ADR yet. Write one when a cross-cutting technical decision needs a durable rationale
(see `ORCA_WORKFLOW.md` §4); task branches must not create or edit documents in this
directory.

Convention: `NNNN-<short-slug>.md` (e.g. `0001-session-store-in-redis.md`), one decision per
file, with status (`proposed` / `accepted` / `superseded`) and the alternatives considered.
